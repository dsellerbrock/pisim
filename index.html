Zero Lab

A Raspberry Pi Zero 2 W on your computer.

Boot a virtual Pi, wire up buttons, knobs and LEDs to its GPIO pins, and drop in your own code to build and run on it.

macOS

Apple Silicon (M1 or newer), macOS 26+. Fastest version.
Download .dmg
  1. Open the .dmg and drag Zero Lab to Applications.
  2. First launch: System Settings → Privacy & Security → Open Anyway (the app isn't notarized by Apple).

Windows

Windows 10 or 11, 64-bit. No WSL needed.
Download installer
  1. Run the installer. If SmartScreen warns, click More info → Run anyway (the app isn't code-signed).
  2. Start Zero Lab from the Start menu.

Linux

64-bit x86 Linux. One file, nothing to install.
Download AppImage
  1. Make it runnable: chmod +x Zero-Lab-*.AppImage (or Properties → Allow executing).
  2. Double-click it to start Zero Lab.
On Windows and Linux the Pi's ARM CPU is emulated, so it runs several times slower than on an Apple Silicon Mac.
